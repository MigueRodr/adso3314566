Posicionamiento en CSS

Normal (static) · Relative · Absolute · Fixed · Sticky

Cada elemento se posiciona segun el flujo normal o se desplaza fuera de el. Observa los ejemplos.

1. POSITION: STATIC (valor por defecto)
Caja 1 - Static (flujo normal)
Caja 2 - Static
Caja 3 - Static
static es el comportamiento normal. Los elementos se colocan en orden, uno tras otro, respetando el flujo del documento. top/left/right/bottom no tienen efecto.
2. POSITION: RELATIVE
Caja 1 - Relative (sin desplazar)
Caja 2 - Relative: top:15px; left:20px
Caja 3 - Static (no se ve afectada por el desplazamiento de la caja 2, el espacio original de la caja 2 se mantiene)
relative: Se desplaza respecto a su posicion original, pero reserva el espacio original. top/left/right/bottom funcionan. El flujo de los demas elementos no cambia.
3. POSITION: ABSOLUTE

Contenedor con position: relative (punto de referencia)

Elemento normal (static)
ABSOLUTE: bottom:10px; right:20px
El elemento absolute se posiciona respecto al ancestro mas cercano con position distinto de static (aqui el div .relative-parent). Se extrae del flujo y no reserva espacio.
Este elemento esta fuera del contenedor relativo, el absolute no le afecta porque esta fuera del flujo.
4. POSITION: FIXED
Contenido normal - Haz scroll vertical para ver el elemento fijo (abajo derecha) que se mantiene en pantalla.
fixed se posiciona respecto a la ventana del navegador (viewport). No se mueve al hacer scroll. En este ejemplo, un pequeño bloque fijo aparece en la esquina inferior derecha. (Ya existe un boton "Volver" fixed arriba a la izquierda y un mini bloque fijo adicional).
5. POSITION: STICKY
SOY STICKY: me mantengo pegado mientras estoy dentro de mi contenedor (top:0)
Contenido 1 - Sigue scrolleando para ver que el sticky se queda arriba hasta que sale de su contenedor.
Contenido 2 - sticky solo funciona dentro de su contenedor con overflow auto.
Contenido 3 - Observa como al salir del area gris, el sticky se va con el scroll.
Contenido 4 - Es util para cabeceras de seccion.
Contenido 5 - Cuando el contenedor termina, el sticky ya no se queda pegado.
sticky: hibrido entre relative y fixed. Permanece "pegado" dentro de su contenedor hasta que el scroll lo alcanza, pero sin salirse del bloque contenedor. Requiere top/left/right/bottom y un contenedor con scroll.
Resumen rapido:
- static: flujo normal, sin desplazamiento.
- relative: se mueve respecto a si mismo, deja hueco.
- absolute: se posiciona respecto al ancestro con position (no static), se saca del flujo.
- fixed: respecto al viewport, no se mueve con scroll.
- sticky: se comporta como relativo hasta que el scroll lo activa, luego se fija dentro de su contenedor.
