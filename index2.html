Conceptos Básicos

01-CHILD (ANIDAR ELEMENTOS)

Creates child elements (nesting).
Crea elementos hijos (anidación).
EJEMPLO
ul>li>a
RESULTADO
<ul>
  <li><a href=""></a></li>
</ul>
parent > child

02-SIBLING (ELEMENTOS HERMANOS +)

Creates sibling elements.
Crea elementos hermanos.
EJEMPLO
section+header+nav
RESULTADO
<section></section>
<header></header>
<nav></nav>
element + element

03-MULTIPLICATION (REPETIR ELEMENTOS)

Repeats elements multiple times.
Repite elementos varias veces.
EJEMPLO
ul>li*3
RESULTADO
<ul>
  <li></li>
  <li></li>
  <li></li>
</ul>
element * number

04-CLASS

Creates a class attribute.
Crea un atributo de clase.
EJEMPLO
div.contenedor
RESULTADO
<div class="contenedor"></div>
element.class

05-CLASSES

Creates multiple class attributes.
Crea múltiples atributos de clase.
EJEMPLO
div.clase1.clase2.clase3
RESULTADO
<div class="clase1 clase2 clase3"></div>
element.class1.class2

06-ID

Creates an ID attribute.
Crea un atributo de ID.
EJEMPLO
nav#menu
RESULTADO
<nav id="menu"></nav>
element#id

07-TEXT (ADICIONAR TEXTO)

Inserts text content.
Inserta contenido de texto.
EJEMPLO
div{Lorem Ipsum Dolor}
a{Click Aqui}
RESULTADO
<div>Lorem Ipsum Dolor</div>
<a href="">Click Aqui</a>
element{text}

08-CUSTOM ATTRIBUTE

Creates custom attributes.
Crea atributos personalizados.
EJEMPLO
a[href=www.google.com]
RESULTADO
<a href="www.google.com"></a>
element[attr="value"]

09-ITEM NUMBERING

Adds consecutive numbers.
Añade números consecutivos.
EJEMPLO
ul>li.num$*3
section>article.sec$$$*3
RESULTADO
<ul>
  <li class="num1"></li>
  <li class="num2"></li>
  <li class="num3"></li>
</ul>
<section>
  <article class="sec001"></article>
  <article class="sec002"></article>
  <article class="sec003"></article>
</section>
$ = 1,2,3...

10-REVERSE NUMBERING @-

Inverts numbering order.
Invierte el orden de numeración.
EJEMPLO
ul>li.num$@-*3
RESULTADO
<ul>
  <li class="num3"></li>
  <li class="num2"></li>
  <li class="num1"></li>
</ul>
$@- = 3,2,1...

11-BASE NUMBERING @n

Defines a base number for sequences.
Define un número base para secuencias.
EJEMPLO
ul>li.num$@3*4
RESULTADO
<ul>
  <li class="num3"></li>
  <li class="num4"></li>
  <li class="num5"></li>
  <li class="num6"></li>
</ul>
$@N = N,N+1,...

12-CLIMB UP ^

Moves up one level.
Sube un nivel.
EJEMPLO
section>article>div^p
RESULTADO
<section>
  <article>
    <div></div>
  </article>
  <p></p>
</section>
^ = up one level

13-GROUPING

Groups elements together.
Agrupa elementos juntos.
EJEMPLO
(header>nav)(section>article)
RESULTADO
<header>
  <nav></nav>
</header>
<section>
  <article></article>
</section>
(group) for complex structures

14-LOREM

Generates placeholder text.
Genera texto de relleno.
EJEMPLO
lorem
lorem20
lorem*5
RESULTADO
Lorem ipsum dolor sit amet...
(Genera texto de relleno con 20 palabras)
(Genera 5 párrafos)
loremN (N = palabras)

15-HTML DOCUMENTS

Creates various HTML document types.
Crea varios tipos de documentos HTML.
EJEMPLO
html:xs → XHTML 1.0 Strict
html:xt → XHTML 1.0 Transitional
html:4s → HTML 4.01 Strict
html:4t → HTML 4.01 Transitional
html:5 → HTML 5
RESULTADO
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <title>Document</title>
  </head>
  <body>
  </body>
</html>
html:5, html:xt, etc.

16-META TAGS

Generates meta tags.
Genera etiquetas meta.
EJEMPLO
meta:vp
RESULTADO
<meta name="viewport" content="width=device-width, initial-scale=1.0">
meta:vp (viewport)

17-CHALLENGE

Generates Emmet challenges for practice.
Genera desafíos de Emmet para práctica.
EJEMPLO
¡Practica todos los conceptos anteriores!
RESULTADO
Crea estructuras HTML complejas combinando
todos los operadores de Emmet aprendidos.
